# SPC Prayer.Com Installation Guide

SPC Prayer.Com can be installed on an iPhone or Android phone as a Progressive Web App (PWA).

Website:

https://katem64.github.io/spc.com/

When the Hostinger production website is ready, use that production URL instead.

## Before You Start

- Use the latest version of Safari on iPhone or Google Chrome on Android.
- Open the website directly in the browser.
- Do not open it inside Facebook, Messenger, Gmail, or another in-app browser.
- Enter the access code provided privately by the SPC administrator.

## iPhone Installation

1. Open **Safari**.
2. Visit https://katem64.github.io/spc.com/.
3. Enter the private access code when requested.
4. Tap the **Share** button. It looks like a square with an upward arrow.
5. Scroll through the options and tap **Add to Home Screen**.
6. Confirm the name **SPC Prayer.Com**.
7. Tap **Add**.
8. Close Safari and open **SPC Prayer.Com** from the iPhone Home Screen.

The Home Screen icon opens the app in its installed web-app mode.

## Android Installation

1. Open **Google Chrome**.
2. Visit https://katem64.github.io/spc.com/.
3. Enter the private access code when requested.
4. Wait for the landing page to load.
5. Tap the Chrome **three-dot menu** in the top-right corner.
6. Tap **Install app**, **Install SPC Prayer.Com**, or **Add to Home screen**. The wording depends on the Android version.
7. Tap **Install** or **Add** to confirm.
8. Open **SPC Prayer.Com** from the Home Screen or app drawer.

Some Android phones show an **Install** banner at the bottom of the page. Tap that banner if it appears.

## If Installation Is Not Available

- Confirm that the address begins with `https://`.
- Use Safari on iPhone or Chrome on Android.
- Refresh the website and wait for the page to finish loading.
- On iPhone, use the Safari Share menu and look for **Add to Home Screen**.
- On Android, open Chrome's three-dot menu and look for **Install app** or **Add to Home screen**.
- If an older version was installed, remove it, reopen the website, and install it again.

## Updating the App

When a new version is released:

1. Open the website in the browser.
2. Refresh the page.
3. If the installed app still shows an older version, remove the Home Screen icon or installed app.
4. Reopen the website and install it again.

## GitHub Testing and Hostinger Production

The GitHub Pages address is used for testing:

https://katem64.github.io/spc.com/

The Hostinger address will be used for the final production deployment. Installations from the GitHub and Hostinger addresses are separate apps. When production is ready, install the app again from the Hostinger address.

## Access Code Privacy

The access code is not included in this public guide. Obtain it from the SPC administrator.
